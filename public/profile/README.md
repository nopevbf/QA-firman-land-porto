# Folder Foto Profil (Public Assets)

Taruh file foto profil Anda di folder ini:
**Path:** `/public/profile/avatar.png` atau `/public/profile/linkedin_profile-badge.png`

### Nama file yang otomatis dideteksi aplikasi:
1. `avatar.png` (Direkomendasikan)
2. `linkedin_profile-badge.png`
3. `profile.png`
4. `avatar.jpg` / `profile.jpg`

Foto yang Anda letakkan di folder ini akan otomatis dimuat dan ditampilkan di tengah kartu profil landing page.
